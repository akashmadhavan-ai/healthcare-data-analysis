# 🏥 Healthcare Data Analysis Platform

## Upload Any Healthcare Dataset And Get Instant Insights

An interactive healthcare analytics platform built using Python and Streamlit that automates:

- Healthcare data cleaning
- Statistical analysis
- Insight generation
- Interactive visualizations
- PDF report generation
- Power BI / Tableau export preparation

Designed for:
- students
- analysts
- researchers
- developers
- healthcare professionals

# ⚡ Quick Start

## Clone Repository

```bash
git clone https://github.com/akashmadhavan-ai/healthcare-data-analysis.git
```

---

## Move Into Project

```bash
cd healthcare-data-analysis
```

---

## Create Virtual Environment

```bash
python -m venv venv
```

---

## Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Run Application

```bash
streamlit run app.py
```
