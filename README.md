# Healthcare Data Analysis

## Problem
Analyze healthcare data to identify factors affecting diabetes risk.

## Tools Used
Python, Pandas, Seaborn, Matplotlib

## Process
- Data cleaning and preprocessing
- Exploratory data analysis
- Visualization of key variables

## Key Insights
- High glucose levels strongly correlate with diabetes
- BMI shows significant impact on risk
- Age has moderate influence

## Outcome
This project demonstrates the ability to analyze structured healthcare data and extract meaningful insights.
